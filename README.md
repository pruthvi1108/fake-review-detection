# 🕵️ Fake Review Detection using NLP & Machine Learning

A Machine Learning and Natural Language Processing (NLP) based system designed to identify fake product reviews by analyzing textual patterns and review behavior.

---

# 📌 Overview

Fake online reviews can mislead customers and affect business credibility.

This project uses NLP preprocessing and Machine Learning models to classify reviews as:

* Genuine Reviews
* Fake/Spam Reviews

---
