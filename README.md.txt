# Fake Review Detection

This project detects fake and genuine product reviews using Machine Learning and NLP techniques.

## Features
- Text preprocessing (lowercase, punctuation removal, stopwords)
- TF-IDF vectorization
- Logistic Regression model
- Custom review prediction

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- NLP (TF-IDF)

## How to Run
1. Clone the repository
2. Install dependencies:
   pip install -r requirements.txt
3. Run the notebook or script

## Output
The model predicts whether a review is **Fake** or **Genuine**.
